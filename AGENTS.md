# Agent Instructions

## Documentation and comments

Write all documentation and code comments in Simplified Technical English (ASD-STE100).

1. Invoke the `simple-english` skill before you write or edit any documentation.
2. Invoke the `simple-english` skill before you write or edit any code comment.
3. Apply these rules to every file, and to your own reports and commit messages.
4. If you edit existing text that does not obey these rules, correct the text.

Note: this rule applies to the current task, not only to future tasks.

## Chat responses

These rules apply to all messages to the human user.

1. Ask a maximum of one question in a response. Then wait for the answer.
2. When you give options, put all of the information about an option in that option.
3. Give the recommendation as the option identifier alone. Do not add information to it.
4. When you refer to a plan item, a spec item, a task item, or a vault item, give the identifier and a description of one sentence. Do not give the identifier alone.
5. Write short responses.
6. Show action items in a list. Do not put an action item in a block of prose.
7. Put the most important content at the start or at the end of the response.
8. Do not add extra content at the end of a response. If the content is important, put it in the body.
